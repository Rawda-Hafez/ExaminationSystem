# Advanced Examination Management System

An Object-Oriented Examination Management System built with C# and .NET.

## 🚀 Features
- **Object-Oriented Architecture**: Utilizes inheritance, polymorphism, encapsulation, and abstraction.
- **Question Types**:
  - True / False Questions
  - Choose One (Single Choice) Questions
  - Choose All (Multiple Choice) Questions
- **Exam Types**:
  - Practice Exam
  - Final Exam
- **Event-Driven Architecture**: Event notifications for exam state changes.
- **Student & Subject Management**: Enroll students, manage courses, and log examination questions and results.

## 🛠️ Built With
- C# (.NET 10.0)
- Console Application

## 💻 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Rawda-Hafez/ExaminationSystem.git
   ```
2. Navigate to the project folder:
   ```bash
   cd ExaminationSystem
   ```
3. Run the application:
   ```bash
   dotnet run
   ```
